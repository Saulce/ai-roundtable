# ai-roundtable

AI 圆桌讨论：几个 AI 角色围绕你给的一个话题各抒己见，直到得出答案（或由你随时叫停），并支持讨论文本的摘要/总结。

## 现状

- 规划与决策：见 [Wayfinder Map](https://github.com/Saulce/ai-roundtable/issues/1)（本仓库 Issues 里的 `wayfinder:map`）。
- 技术选型：LangGraph（调研见 [docs/research/framework-selection.md](docs/research/framework-selection.md)）。
